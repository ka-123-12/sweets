# Sweet Delight - スイーツショップサイト

架空のスイーツショップ「Sweet Delight」のWebサイトです。
HTML/CSSで制作しており、PC・スマホで閲覧可能です。

---

## サイト内容
- **Aboutページ**
素材の美味しさや風味を最大限に生かしたスイーツのコンセプトを紹介
- **Menuページ**
旬のフルーツや高級素材を使ったケーキを写真と説明で紹介
- ストロベリーケーキ（あまおう使用）
- ブルーベリーチーズケーキ（フランス産チーズ使用）
- チョコレートケーキ（ベルギー産チョコ使用）
- **Shopページ**
オンラインストア準備中の案内やメール登録、SNS情報

---

## 工夫した点
- **レスポンシブデザイン**
スマホ・タブレットでも見やすく操作しやすいUI
- **写真中心のデザイン**
スイーツの魅力を視覚的に伝える
- **色使い・配色**
パステルや暖色を使用して温かく食欲をそそる雰囲気を演出
- **各ページの構成**
About / Menu / Shop とわかりやすく整理
- **SNS連携**
Instagram / YouTube / Twitterへのリンクで情報発信を想定
- **オンラインストア準備**
メール登録フォームでユーザーとの接点を設置

---

## 技術スタック
- HTML5 / CSS3 
- レスポンシブデザイン対応（メディアクエリ使用）
- フォーム・リンクでのユーザーアクションを想定
